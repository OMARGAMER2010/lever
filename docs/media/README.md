# Capture details

Prepared on 2026-09-13. Lever remains v1.0.0.

| Files | Source and scope |
|---|---|
| `lever.jpg`, `lever.mp4` | Supplied 30-second recording: still at 2 s, excerpt 0.7–2.0 s. Cropped to the upper app area, excluding recent-file paths. |
| `kirby.jpg`, `kirby.mp4` | Same recording: still at 18 s, excerpt 17.8–19.4 s. Kirby's Adventure tutorial, cropped to the game area. |
| `elden-ring.jpg`, `elden-ring.mp4` | Same recording: still at 24 s, excerpt 24–25.8 s. Metal HUD retained as recorded. No sustained-performance claim. |
| `super-mario-odyssey.jpg` | Live capture of the main menu in the installed Ryujinx 1.3.3. Emulator chrome and status bar cropped out. No gameplay or Lever launch claim. |

Images are JPEG. Videos are H.264 MP4, 30 encoded frames per second, with the `moov` index
at the beginning for progressive playback. Encoding rate is not a game-performance measurement.
Audio is omitted entirely. The original recordings are not included.

The README uses relative image paths and explicit MP4 links with `?raw=true`, rather than
assuming repository MP4 files render as embedded videos. A browser may download these links;
the downloaded files can be played locally. GitHub's separate attachment upload workflow is
documented [here](https://docs.github.com/en/get-started/writing-on-github/working-with-advanced-formatting/attaching-files).
